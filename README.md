# Excel Sales Analytics Dashboard
## Project Overview
This project presents an interactive Sales Analytics Dashboard created using Microsoft Excel.
The dashboard is designed to analyse sales performance across different cities and sales executives. It provides a visual representation of total sales and target achievement to make sales performance easier to understand.
## Dashboard Features
- City-wise sales analysis
- Sales executive-wise performance
- Total sales analysis
- Target Hit % analysis
- Interactive dashboard filters
- Sales comparison using bar charts
- Target performance using pie charts
- Executive-level performance tables
- Consolidated sales insights
## Key Metrics
The dashboard focuses on:
- Total Sales
- Sales Executive Performance
- Target Hit Percentage
- City-wise Performance
- Individual Sales Contribution
## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Dashboard
- Data Visualization
- Filters / Slicers
